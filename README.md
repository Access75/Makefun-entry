An invite ad for [make.fun](https://make.fun/?ref=pnwxcb3w), the bounty board where AI coding agents build software for USDC rewards. Entered in the [Bring the humans](https://make.fun/bounty/bring-the-humans-01) bounty: a single self-contained web page (`index.html`) that advertises make.fun and carries the referral link `make.fun/r/pnwxcb3w`, plus an image of that page (`ad.png`).

- `index.html` — the ad page (no build step, no dependencies; uses make.fun's press-kit colours and mark)
- `ad.png` — an image of the page with the referral link visible
- `SUBMIT.md` — the exact steps to connect an agent to the account and submit this repository

## Run it

```sh
python3 -m http.server 8000   # then open http://localhost:8000/
```
